# つたえる帳

大きな字の**週間予定表**と、伝えたいことを書いた**メモ**を作って、リンクで送ったり、印刷して渡したりできるページです。
（以前の名前は「予定表メーカー」です。アドレス `yannsi.github.io/yotei-hyo/` は、送ったリンクや印刷したQRが開けなくならないよう、そのままにしています）

- **はじめは空**：例は入っていません。書きかけの下書きはその端末に残ります。
- **お金も設置もいらない**：使う人は紙か、今あるスマホのブラウザだけ。
- **データはリンクの中だけ**：中身は圧縮してURLの `#` より後ろに入れます（予定表は `#p=`、メモは `#m=`）。`#` より後ろはサーバーに送られないので、どこにも保存されません。リンクを手にした人は誰でも読めるので、見られて困ることは書かないでください。
- **受け取った人は見て印刷するだけ**：送られてきたリンクを開くと、作る道具は隠れて、中身と「印刷する」ボタンだけが出ます。下の「編集する・新しく作る」から作る画面に戻れます。
- **名前を付けて送る**：コピーやLINEで送るとき、リンクの上に「予定表：〇〇さんの予定」「メモ（お母さんへ）：あしたは9時に…」の一文が付きます。LINEでは「つたえる帳」のカードが出ます（`og.png`）。
- **オフライン**：一度開くと、ネットなしでも開けます。

## タブ

| タブ | できること |
|---|---|
| 予定 | 毎週の予定・1回きりの予定と、困ったときの連絡先を入れる。リンク・QRを作る |
| 週の表 | A4横で印刷する週の表。土曜は青・日曜は赤。右上のQRを読むと同じ表がスマホで開く。受け取った人のスマホでは曜日ごとの縦の一覧 |
| 今日 | 置いておくスマホ用。今日の予定だけを大きく出し、次の予定に「つぎ」と印をつける。「画面を消さない」付き |
| メモ | 宛先・差出人・要点（黄色の枠で大きく）・詳細・確認事項（受け取った人がチェックできる）。A4縦で印刷 |

## 置き方（GitHub Pages）

このフォルダの中身をリポジトリの一番上に置き、Settings → Pages で `main` ブランチを公開します。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | ページ本体 |
| `lib/qrcode.js` | QRを作る部品（Kazuhiko Arase、MITライセンス） |
| `sw.js` | オフラインで開けるようにする仕組み（同じドメインの他の作品の保存には触らない） |
| `og.png` | LINEなどでリンクを送ったときのカードの絵 |
| `manifest.webmanifest`, `icon-*.png` | ホーム画面に追加したときの名前とアイコン |
