# 予定表メーカー

大きな字の週間予定表を作って、印刷したり、リンクで家族に送ったりできるページです。

- **お金も設置もいらない**：使う人は紙か、今あるスマホのブラウザだけ。
- **データはリンクの中だけ**：予定は圧縮してURLの `#` より後ろに入れます。`#` より後ろはサーバーに送られないので、どこにも保存されません。
- **印刷して貼る**：A4横で、土曜は青・日曜は赤。右上のQRを読むと同じ表がスマホで開きます。
- **受け取った人は見て印刷するだけ**：送られてきたリンクを開くと、作る道具は隠れて、予定と「印刷する」ボタンだけが出ます。スマホでは曜日ごとの縦の一覧、パソコンでは週の表です。直したいときは下の「この予定表を直す・自分用に作る」から。
- **置いておくスマホ用の「今日」画面**：今日の予定だけを大きく出し、次の予定に「つぎ」と印をつけます。
- **オフライン**：一度開くと、ネットなしでも開けます。

## 置き方（GitHub Pages）

このフォルダの中身をリポジトリ（例：`yannsi/yotei-hyo`）の一番上に置き、Settings → Pages で `main` ブランチを公開します。

## ファイル

| ファイル | 中身 |

| `index.html` | ページ本体 |
| `lib/qrcode.js` | QRを作る部品（Kazuhiko Arase、MITライセンス） |
