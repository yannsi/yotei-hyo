# つたえる帳

大きな字の**週間予定表**と、伝えたいことを書いた**メモ**を作って、リンクで送ったり、印刷して渡したりできるページです。
（以前の名前は「予定表メーカー」です。アドレス `yannsi.github.io/yotei-hyo/` は、送ったリンクや印刷したQRが開けなくならないよう、そのままにしています）

- **はじめは空**：例は入っていません。書きかけの下書きはその端末に残ります。
- **お金も設置もいらない**：使う人は紙か、今あるスマホのブラウザだけ。
- **データはリンクの中だけ**：中身は圧縮してURLの `#` より後ろに入れます（予定表は `#p=`、メモは `#m=`）。`#` より後ろはサーバーに送られないので、どこにも保存されません。リンクを手にした人は誰でも読めるので、見られて困ることは書かないでください。
- **受け取った人は見て印刷するだけ**：送られてきたリンクを開くと、作る道具は隠れて、中身と「印刷する」ボタンだけが出ます。下の「編集する・新しく作る」から作る画面に戻れます。
- **名前を付けて送る**：コピーやLINEで送るとき、リンクの上に「予定表：〇〇さんの予定」「メモ（お母さんへ）：あしたは9時に…」の一文が付きます。LINEでは予定表なら「予定表」、メモなら「メモ」のカードが出ます（`og-yotei.png`・`og-memo.png`）。メモのリンクはカードを分けるため `memo.html` から入り、すぐ本体へ移ります。
- **オフライン**：一度開くと、ネットなしでも開けます。

## 最初の画面

開くと「何を作りますか？」と出て、**予定表**か**メモ**を選びます。書きかけがある方には「書きかけがあります」と出ます。上の「つたえる帳」を押すと、いつでもこの画面に戻れます（送られてきたリンクを開いたときは出ません）。

## タブ

| タブ | できること |
|---|---|
| 予定 | 毎週の予定・1回きりの予定と、困ったときの連絡先を入れる。旧暦と沖縄の行事を出すかを選ぶ。リンク・QRを作る |
| 週の表 | A4横で印刷する週の表。土曜は青・日曜は赤。右下のQRを読むと同じ表がスマホで開く。受け取った人のスマホでは曜日ごとの縦の一覧。選んだときは各日に旧暦の日付と沖縄の行事（旧正月・ジュウルクニチー・浜下り・ユッカヌヒー・七夕・旧盆・十五夜・ムーチー・御願解き・清明・トゥンジー）が出る |
| 今日 | 置いておくスマホ用。今日の予定だけを大きく出し、次の予定に「つぎ」と印をつける。「画面を消さない」付き。旧暦を選んだときは日付の下に旧暦と行事 |
| メモ | 宛先・差出人・要点（黄色の枠で大きく）・詳細・確認事項（受け取った人がチェックできる。チェックは受け取った人のスマホにだけ残る）。A4縦で印刷。印刷のQRは模様の細かさに合わせて26〜40mmにし、長すぎて読み取りにくいメモでは紙にQRを付けず、画面で知らせる |

## 置き方（GitHub Pages）

このフォルダの中身をリポジトリの一番上に置き、Settings → Pages で `main` ブランチを公開します。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | ページ本体 |
| `lib/qrcode.js` | QRを作る部品（Kazuhiko Arase、MITライセンス） |
| `sw.js` | オフラインで開けるようにする仕組み（同じドメインの他の作品の保存には触らない） |
| `memo.html` | メモのリンクの入口（「メモ」のカードを出して、すぐ本体へ移る） |
| `og-yotei.png`, `og-memo.png` | LINEなどでリンクを送ったときのカードの絵（絵を変えるときは、LINEが前の絵を覚えているのでファイル名も変える） |
| `manifest.webmanifest`, `icon-*.png` | ホーム画面に追加したときの名前とアイコン |

## 旧暦について

旧暦は、新月と中気（太陽の位置）から日本時間で計算した2024〜2045年の表をページに埋め込んでいます（ネットにつながなくても出ます）。中国の旧暦とは日付が1日ずれる年があります（例：2027年の旧正月は日本の旧暦で2月7日）。2033年は決まりだけでは月が決まらない年なので、慣例どおり閏11月としています。
